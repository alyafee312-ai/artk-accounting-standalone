# مراجعة نقل نظام أرتك من Floot

## الحالة
المستودع يحتوي على ملفات مصدر أصلية من Floot، وواجهة معاينة مستقلة، وإعداد بناء Android تجريبي.

## ما يجب التحقق منه قبل أي تشغيل مالي
1. استكمال المكونات الأصلية الناقصة واعتمادياتها.
2. عزل واجهات الحسابات عن مسارات API الخاصة بـ Floot.
3. نقل قواعد المحاسبة والتحقق من العمليات مع اختبارات عدم تكرار السندات.
4. تخزين SQLite مشفر بمفاتيح Android Keystore.
5. دخول أول مرة، ثم فتح ببصمة أو PIN مع آلية استرداد.
6. اختبارات العمل دون إنترنت وإعادة التشغيل وانقطاع الكهرباء.
7. مزامنة مع خادم مستقل مع معرفات طلبات فريدة وحل التعارضات.
8. نسخ احتياطي مشفر واختبار الاستعادة قبل نقل أي بيانات.
9. بناء APK واختباره على هاتف فعلي.

## قيود
لا ترفع أسرار Floot أو مفاتيح Supabase أو بيانات المستخدمين الحقيقية.
استيراد العملاء والمشاريع والشعار مؤجل.
لا تنشر إلى الإنتاج دون موافقة المالك.
