# أرتك المحاسبي — إدارة الورشة

نسخة Android مستقلة عن Floot، تستخدم الواجهة الأصلية ومحرك المحاسبة المنقول، مع SQLite محلية مشفرة. هذا فرع تطوير تجريبي لاستخدام بيانات الاختبار حتى اجتياز بوابات الإصدار.

## التشغيل والتحقق

```sh
npm ci
npm test
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

التخزين الدائم في تطبيق Android فقط؛ لا تُستخدم معاينة المتصفح بوصفها قاعدة مالية. عند أول تشغيل، أنشئ PIN ثم كلمة مرور لحساب المدير المحلي `admin`. يمكنك إضافة المحاسب والموظف من المستخدمين. لا توجد كلمة مرور افتراضية أو بيانات مالية حقيقية.

## تنظيم المصدر

- `floot-source/components/`: مكونات Floot الأصلية، مع تكييف النسخ والحسابات المحلية.
- `floot-source/helpers/`: أدوات العرض والحساب والتقارير والوثائق الأصلية، وبعض مصادر الخادم المؤرشفة غير الداخلة في البناء.
- `src/local/`: المحرك المحلي، محول SQLite، الترحيلات، المصادقة، النسخ والاستعادة، واختبارات التكامل.
- `src/nativeQa.tsx`: تحقق محاكي معزول، يدخل نسخة CI منفصلة فقط؛ لا يدخل APK القابل للتنزيل.
- `.github/workflows/android-preview.yml`: الاختبارات وبناء APK والتحقق على محاكي Android.

حزمة المعاينة `com.artk.accounting.standalone` منفصلة عن الأصل `com.artk.accounting`. لا تستخدم المستودع المختلف `artk-decor-ads` لهذه المهمة.

راجع [حالة النقل](MIGRATION_STATUS.md)، [المعمارية](docs/LOCAL_ARCHITECTURE.md)، و[بوابات الإصدار](docs/RELEASE_GATES.md). لا دمج في main أو نشر إنتاجي دون موافقة المالك. ربط Google Drive مؤجل، ولا يوجد اتصال بخوادم Floot للعمليات اليومية.
